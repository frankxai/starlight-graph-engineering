# Starlight Graph Engineering

Thin **canon** for Starlight agentic graph engineering: vocabulary, contract, taxonomy, living index, harness map, and research pointers.

> Graph engineering = making an agent system’s organization **explicit, executable, observable, recoverable, evolvable**.

It extends loop engineering; it does not replace it.

**Owner:** Loop & Graph Engineer  
**Schema:** `starlight.graph-engineering.v1`  
**Status:** canonical doctrine home (thin — not a runtime)

## What this repo is

The estate’s draft single source of truth for graph-engineering **law and maps**. Runtimes stay in their planes:

| Work-graph kernel (Layer A) | [SIS #102](https://github.com/frankxai/Starlight-Intelligence-System/pull/102) |
| Cross-runtime execution graph | [agentic-ops #16](https://github.com/frankxai/agentic-ops/pull/16) |
